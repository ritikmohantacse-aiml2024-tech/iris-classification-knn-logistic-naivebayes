# iris-classification-knn-logistic-naivebayes
Machine Learning classification project using the Iris dataset. Compared KNN, Logistic Regression, and Naive Bayes models to predict Iris flower species.
# Iris Flower Classification

## Project Overview
This project predicts the species of an Iris flower using Machine Learning.

## Algorithms Used
- K-Nearest Neighbors (KNN)
- Logistic Regression
- Naive Bayes

## Dataset
The Iris dataset contains 150 flower samples with:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target:
- Iris-setosa
- Iris-versicolor
- Iris-virginica

## Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Evaluation
- Accuracy Score
- Confusion Matrix
- Classification Report
